# NetHackChat

iPhone のブラウザで遊べる、AI(Claude)と一緒に遊ぶ NetHack 風ローグライクです。
サーバー不要の静的 Web アプリで、ブラウザから Claude API を直接呼び出します。

## 遊び方

1. このリポジトリを静的ホスティングで公開するか、ローカルで配信します。

   ```sh
   # 例: ローカル配信
   python3 -m http.server 8000
   # → iPhone の Safari で http://<PCのIP>:8000 を開く
   ```

   GitHub Pages(Settings → Pages → ブランチを公開)でもそのまま動きます。

2. 画面右下の「⚙️ 設定」から Claude API キー(`sk-ant-...`)を登録します。
   **キーはこの端末の localStorage にのみ保存され、Anthropic API 以外へは送信されません。**

3. キャラクターを作成して冒険へ。

## 機能

- **プレイヤーキャラクター**
  - プレイ開始時に作成済みキャラクターから選択
  - 新規作成時はカメラロールから外見画像を選択 → AI が名前・性格・能力値・背景を生成
  - 画像を選ばない場合はランダム生成(画像なし)
  - 名前と性格はいつでも編集可能(スタート画面・プレイ中どちらからでも)
- **ゲームルール**
  - 成長・獲得アイテムは次のプレイに持ち越さない(ローグライク)
  - アイテム(未識別のポーション・巻物)の使用効果は毎回 AI が判定
  - 自由入力(「大声で歌う」「剣を構えて突撃」など)の結果も AI が判定し、ゲーム効果として反映
  - 移動ボタンを押しっぱなしにすると、通路を道なりに自動移動(敵・アイテム・階段・ドアで停止)
  - マップをタップするとそのマスの情報を確認できる
  - ペット(子犬)、ショップ(購入と売却)、モンスターハウスを再現
  - ドア・隠しドア(「調べる」で発見)・蹴破りに対応
  - 魔法の杖(打撃/眠り/炎/穴掘り/瞬間移動)とツルハシで壁掘りが可能
  - アイテムは投げる・捨てる・売るに対応。杖や投擲の方向は、自由入力で指示が
    無ければ方向ボタンで指定する。着弾対象・消費・回数はエンジンが正しく判定
  - ダンジョンは部屋+短い通路構成(迷路は作らない)
  - 敵はアイテムをドロップし、宝箱からも様々なアイテムが見つかる(罠つきのことも)

NetHack の行動一覧と自由入力の対応状況は [docs/nethack-coverage.md](docs/nethack-coverage.md) を参照。

## モデルルーティング設計

タスクをフェーズ分解し、それぞれ「品質基準を満たす最もコスト効率の良い Claude モデル」に
割り当てています。弱いモデルには網羅的なシステムプロンプト+構造化出力(JSON スキーマ)で
品質を補っています。設定画面からモデルは変更可能です。

| タスク | 頻度 | 既定モデル | 単価(入/出 per MTok) | 理由 |
|---|---|---|---|---|
| 自由入力の解釈・行動判定 | 毎ターン級(高頻度) | `claude-haiku-4-5` | $1 / $5 | 分類+短い実況の生成。詳細な GM プロンプトと JSON スキーマで品質担保 |
| アイテム効果判定 | 頻繁 | `claude-haiku-4-5` | $1 / $5 | 効果は許可リストから選択する構造化タスク |
| 画像からのキャラ生成 | キャラ作成時のみ | `claude-sonnet-5` | $3 / $15 | 画像解析の品質が必要。低頻度なのでコスト影響は小さい |
| フォールバック | 判定失敗時のみ | `claude-sonnet-5` | $3 / $15 | Haiku の呼び出しが失敗したときに 1 回だけエスカレーション |

概算コスト: 行動判定 1 回 ≒ $0.002、キャラ生成 1 回 ≒ $0.01 程度。

AI に繋がらない場合(キー未設定・通信失敗)でも、アイテム効果はローカルの
運任せテーブルで判定されるため、ゲーム自体は継続できます。

## 構成

```
index.html        画面構造
css/style.css     モバイル向けスタイル
js/config.js      モデルルーティング設定・localStorage
js/api.js         Claude API クライアント(直接ブラウザアクセス+フォールバック)
js/ai.js          AIタスク(自由入力解釈 / アイテム判定 / 画像キャラ生成)
js/data.js        モンスター・アイテムのデータテーブル
js/dungeon.js     ダンジョン生成(部屋+通路、ショップ、モンスターハウス)
js/game.js        ゲームエンジン(ターン制、戦闘、効果適用、道なり移動)
js/ui.js          描画・入力・モーダル
```

## 注意

- 本作は NetHack にインスパイアされたオリジナルのローグライクであり、
  NetHack 本体([NetHack/NetHack](https://github.com/NetHack/NetHack))の移植ではありません。
- API キーをブラウザに保存する構成のため、共有端末での利用は避けてください。
