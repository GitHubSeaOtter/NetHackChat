# NetHack でできる事と自由入力の対応状況

NetHack の主要コマンド・行動をリストアップし、NetHackChat の自由入力
(および操作ボタン)でどう対応しているかを整理したもの。

凡例:
- **エンジン対応** … ゲームルールとして決定論的に処理される(消費・効果対象・方向を正しく判定)
- **AI演出対応** … 自由入力を AI が `special` として解釈し、許可リスト内の効果+実況で反映
- **未対応** … 現時点では効果なし(AI が実況のみ返すことはある)

## 自由入力の仕組み

自由入力は毎回 AI(既定: `claude-haiku-4-5`)が解釈し、

1. 上記の**エンジン対応コマンド**に変換できるものは変換して実行
   (`throw`/`zap`/`kick` で方向の指示が無い場合は、ゲームが方向ボタンでの指定を求める)
2. 変換できない創造的な行動は、許可リスト内の効果+性格を反映した実況として反映
3. アイテムの消費・投擲の着弾・杖のビーム対象・売買の金額などは、
   AI 任せにせず**エンジンが決定論的に処理**する

という方針で NetHack らしい行動の幅を再現している。
