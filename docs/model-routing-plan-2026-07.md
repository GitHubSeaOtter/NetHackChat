# NetHackChat 改良(2026-07)モデルルーティング計画

model-routing スキルに基づく計画書。設計(上位モデル)の成果物を
「下位モデルが質問ゼロで完走できる実行指示書」として残し、次回の改修でも再利用する。

## 依頼内容

1. キーパッドをセンターに寄せる(右列: 上から 持ち物/拾う/開ける、左列: 上から 降りる/調べる)
2. NetHack 本家([NetHack/NetHack](https://github.com/NetHack/NetHack))のゲームバランスに近づける
3. 空腹システム(食料で回復)
4. ペットが物を拾う・落とす
5. 新たなペットを手懐けられる

## 品質基準(受け入れ条件)

- [ ] `node --check` が js/*.js 全ファイルで成功する
- [ ] ブラウザ実機動作: キャラ作成→冒険開始→300ターン経過してもコンソールエラーが出ない
- [ ] `#action-right` のボタンが上から「持ち物」「拾う」「開ける」、`#action-left` が上から「降りる」「調べる」、D-pad が中央
- [ ] 空腹度がターン経過で減り、食料で回復し、0 になると HP が減って餓死しうる。HUD に空腹状態が表示される
- [ ] 命中判定(d20)・ダイスダメージ・レベル必要経験値の倍々曲線・低速自然回復・寝ているモンスター・時間経過での増援が入る
- [ ] ペットが床のアイテム(宝箱・金貨・値札付きを除く)をくわえ、後で落とす
- [ ] 食料を動物系モンスターに投げる、または tame_adjacent 効果で新しいペットになる。ペットは階段で隣接(距離2以内)していれば同行する
- [ ] AI プロンプト(judge)が空腹・手懐けを知っており、既存の自由入力機能が壊れない

// プレイヤーダメージ: 武器dice(素手 1d3) + str補正(16+:+1, 18+:+2) + buff

// 経験値: レベルLからL+1 に 10 * 2^L(倍々)。レベルアップHP: max(3, 1d8 + (con-10)/3)
// 自然回復: 衰弱していなければ max(3, 12 - level) ターンに1

function petAt(x, y)                       // 位置のペット
function tameMonster(m)                    // 敵→ペット変換(店主は不可)
// ペットの1ターン: 敵(視界6内)戦闘 > 拾う(35%, carrying<2, 宝箱/金貨/値札除外)
//   > 落とす(隣接時25% / それ以外5%) > 追従(距離2超) > 40%ランダム歩き
// 階段: プレイヤーから距離2以内のペットのみ同行。残りは「はぐれた」

### エッジケースと対応

| 状況 | 期待動作 |
|------|---------|
| nutrition が 1500 のとき食べる | 「満腹でこれ以上食べられない!」で不発(ターン消費なし) |
| nutrition 0 が続く | 毎ターン HP-1、HP0 で死因「餓死」 |
| 祈り: 衰弱/餓死寸前 | nutrition=900 に回復(HP 回復より優先) |
| 祈り: HP < max(6, maxHp/7) | 全回復(従来の 35% 閾値から本家準拠に厳格化) |
| ペット満載(2個)で床にアイテム | 拾わない |
| 店の商品(price 付き)の上にペット | 拾わない(万引き防止) |
| 店主に食料を投げる | 手懐け不可(animal でないので床に落ちるだけ) |
| ペットが死ぬ | くわえていた物を全てその場に落とす |
| 階段を降りるときペットが遠い | そのペットは失われ「〜とはぐれてしまった…」 |
| tame_adjacent で隣接敵なし | 従来どおり「相手はいなかった」 |
| 旧 ally 機構 | 廃止。tame は必ずペット化(以降は階を跨いで同行) |
